Minesweeper TUI — Full Feature List
====================================

Core Gameplay
- Classic Minesweeper played in the terminal (TUI)
- ASCII/text-based interface
- Mouse support
- Flagging mines
- Uncovering squares
- Chording (auto-open all surrounding unflagged cells when flag count matches a number)
- First-click safety (optional first-marked cell, shown as 'X' on import/export)
- No-guess / logic-only game modes (boards guaranteed solvable without guessing)
- Chord via keyboard (F / Enter on an uncovered square) or mouse (left button)

Boards & Difficulty
- Preset difficulties: Beginner, Intermediate, Expert
- No-guess variants of each preset difficulty
- Custom board size (width, height, mine count)
- Custom board range from 4x4 up to screen size
- Deterministic random board generation via seed

Difficulties & Sizes
- Beginner:         9x9,   10 mines
- Beginner - No guess: 9x9,   10 mines
- Intermediate:     16x16,  40 mines
- Intermediate - No guess: 16x16,  40 mines
- Expert:           30x16,  99 mines
- Expert - No guess:  30x16,  99 mines
- Custom:           4x4 up to screen size, >0 mines
- Custom defaults:  30x30, 160 mines

Command-Line Flags
- -w / --width      WIDTH — Width of board
- -h / --height     HEIGHT — Height of board
- -m / --mines      MINES — Number of mines in grid
- -d / --difficulty LEVEL — Difficulty (Beginner / Intermediate / Expert)
- -n / --no-guess        — Generate a board that does not require guessing
- -i / --import FILE     — Import board from file
- -e / --export FILE     — Export board to file
- -s / --seed SEED       — Seed for randomly generated board
- -H / --highscores      — Show highscores
- --no-save          — Do not save highscores
- --no-color         — Do not use color
- Validation of incompatible option combinations (e.g. width/height/mines with difficulty;
  no-guess requires difficulty; import/export cannot be used together; import incompatible
  with board options)

Keyboard Controls
- Enter — Uncover a covered square
- Enter — Chord an uncovered square
- Arrow keys / Vim keys — Move the cursor
- F — Flag a square

Mouse Controls
- Left button — Uncover a covered square; Chord an uncovered square
- Right button — Flag a square

Boards Loading & Saving
- Import/export boards using plain-text ASCII files
- File symbols:
    . — Empty cell
    * — Mine
    X — First click (optional)

Highscores
- Highscores are saved by default
- Ability to disable highscore saving (--no-save)
- Ability to view highscores (--highscores)

Visuals & Output
- Optional colored text output
- Color can be disabled (--no-color)
- Program version and help output (via argp)

Build & Installation
- Built with make
- Nix support (nix run github:ZhaolunYin/minesweeper-tui)
- Dependencies: make, ncurses
